# SLA первого ответа на обращения

Учебный проект по анализу работы поддержки на **полностью синтетических данных**. Все 600 обращений сгенерированы программой; они не относятся к реальной компании, сотрудникам или клиентам. Показатели демонстрируют расчёт, а не фактические результаты работы.

## Вопрос и метод

Какая доля обращений получила первый ответ в установленный срок для каждого приоритета? Python воспроизводимо генерирует учебную выборку с фиксированным seed; SQLite классифицирует обращения на дату среза `2024-04-02 00:00:00`. Нормативы условные: 60 минут для `high`, 240 минут для `normal`; считаются календарные минуты без учёта рабочих часов.

Срок соблюдён, если ответ получен не позднее дедлайна. Просроченным считается ответ после дедлайна или отсутствие ответа, когда дедлайн уже наступил. Обращение без ответа с ещё не наступившим дедлайном остаётся в ожидании. Ответ после даты среза на этот момент не виден. Обращения, созданные после среза, исключаются. Доля соблюдения рассчитывается по обращениям с определившимся исходом: соблюдено / (соблюдено + просрочено); если исходов нет, результат `NULL`.

Срез выбран после истечения сроков всех сгенерированных обращений. Значения обусловлены правилами генерации, их нельзя использовать как оценку реального SLA или доказательство причин различий.

## Запуск и проверка

Нужен Python 3.10 или новее, сторонние библиотеки не требуются. Из корня проекта:

```shell
python analyze.py
python -m unittest discover -s tests -v
```

Результат сохраняется в [outputs/sla_summary.csv](outputs/sla_summary.csv). Запрос находится в [analysis.sql](analysis.sql). Тесты проверяют ответ ровно в срок, опоздание, отсутствие ответа, ответ после среза, ещё не наступивший дедлайн и пустой знаменатель. Расчёты SQL дополнительно сверены с независимым расчётом Python на сгенерированном наборе. Данные и нормативы не предназначены для оценки фактической работы службы поддержки.

Перед расчётом проверяются даты в формате `YYYY-MM-DD HH:MM:SS`, положительный целочисленный норматив и допустимый приоритет. Ответ раньше создания обращения отклоняется с ошибкой. Даты условные, без часового пояса; перенос проекта на реальные данные потребует отдельного определения часовых поясов и рабочих часов.
